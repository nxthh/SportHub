# SportsHub

SportsHub is a modern sports discovery platform built with Next.js. It showcases live and upcoming sports events, category-based browsing, and a polished responsive experience for fans who want to explore the world of athletics in one place.

## Features

- Explore sports categories and disciplines
- Browse featured live and upcoming events
- View a clean, modern landing experience
- Responsive design with light/dark mode support
- Built with TypeScript and Tailwind CSS for a fast, scalable frontend

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Zod and React Hook Form

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open http://localhost:3000 in your browser.

## Available Scripts

- `npm run dev` — run the app locally
- `npm run build` — create a production build
- `npm run start` — start the production server
- `npm run lint` — check for lint issues

## Project Structure

- `src/app` — application routes and pages
- `src/components` — reusable UI and feature components
- `src/context` — app state providers such as auth and favorites
- `src/lib` — utilities, validation, SEO helpers, and config
- `src/services` — API/service integrations
